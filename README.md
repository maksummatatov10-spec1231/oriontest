# Orion Sandbox Enhanced — моды

Два самодостаточных SWF (меню внутри файла, ничего снаружи не нужно):

| Файл | Что внутри |
|---|---|
| `orion_menu.swf` | Игра + меню разработчика |
| `orion_experemental.swf` | То же + 120 FPS и блок настроек (графика — каркас) |

## Меню разработчика

Открывается на **Right Shift** (или Shift) в мире. Окно можно тащить за шапку.

- уровень, HP, режим бога, скорость
- выдать предмет по ID
- спавн босса кликом
- время: утро / день / вечер / ночь или часы:минуты
- в experimental: поле FPS

Полезные ID: 34 кирка, 36 железная кирка, 42 золотой меч, 43 обсидиановый меч, 64 зелье, 138 Громон.

Запуск: Adobe Flash / Ruffle / любой плеер SWF.
